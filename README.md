# بات قیمت دلار، طلا، نقره، مس و کوین‌ها (Telegram Serverless)

## ساختار
- `tgcloud/schema.js` — جدول کش و کول‌داون
- `tgcloud/lib/config.js` — **همه‌ی تنظیمات و کلید CMC اینجاست**
- `tgcloud/lib/sources.js` — دریافت قیمت از TGJU و CoinMarketCap (با کش مشترک)
- `tgcloud/lib/bot.js` — نمایش برد قیمت، کول‌داون یک‌دقیقه‌ای هر کاربر
- `tgcloud/lib/publish.js` — ارسال پست به کانال با دکمه‌ی «مشاهده قیمت آیتم‌های دیگر»
- `tgcloud/handlers/message.js` و `callback_query.js` — پاسخ به پیام و دکمه‌ها
- `tgcloud/endpoints/publishPrices.js` — ارسال به کانال (فقط ادمین)
- `.github/workflows/publish-prices.yml` — تریگر هر ۳۰ دقیقه

## مراحل راه‌اندازی
1. در BotFather ربات را بسازید، سپس وارد بخش **Serverless** همان ربات شوید و آن را روشن کنید.
2. کانال را بسازید و ربات را به‌عنوان **ادمین** کانال با دسترسی **Post messages** اضافه کنید. (BotFather کلید جداگانه‌ای برای ارسال به کانال ندارد؛ دسترسی ادمین کانال همان کار را می‌کند.)
3. آیدی عددی خودتان را در تلگرام پیدا کنید.
4. `tgcloud/lib/config.js` را پر کنید:
   - `BOT_USERNAME`، `CHANNEL_ID`، `ADMIN_ID`
   - `CMC_API_KEY` ← کلید CoinMarketCap
   - نماد مس (`PUT_COPPER_SYMBOL`) و واحد آن
5. ترمینال پروژه:
   ```
   npm install
   npx tgcloud login        # توکن CLI را از بخش Serverless ربات وارد کنید
   npx tgcloud push
   npx tgcloud migrate
   ```
6. در GitHub: یک ریپو بسازید، این پروژه را push کنید، سپس:
   - Secret با نام `TGCLOUD_TOKEN` (همان توکن CLI)
   - Variable با نام `ADMIN_ID`
7. تست دستی: از تب Actions گزینه‌ی **Run workflow** را بزنید، یا در ترمینال:
   ```
   npx tgcloud run endpoints/publishPrices '{}' --ctx '{"initData":{"user":{"id":YOUR_ID}}}'
   ```

## قوانین کول‌داون
- هر کاربر بین دو درخواست قیمت باید ۶۰ ثانیه صبر کند (دستور یا دکمه).
- تلگرام نمی‌تواند دکمه را خاکستری کند؛ بنابراین در زمان کول‌داون، زدن دکمه با پیام «لطفاً N ثانیه صبر کنید» جواب داده می‌شود.
- داده‌ی TGJU ۶۰ ثانیه و داده‌ی CoinMarketCap ۱۲۰ ثانیه کش مشترک دارد؛ یعنی حتی با هزار کاربر، در هر دو دقیقه فقط یک درخواست به CMC می‌رود.

## هشدارها
- **TGJU API رسمی ندارد.** این پروژه از endpoint عمومی سایت (`call4.tgju.org/ajax.json`) استفاده می‌کند. قبل از استفاده‌ی عمومی، شرایط استفاده‌ی TGJU را بخوانید یا از آن‌ها اجازه بگیرید. ممکن است سایت این درخواست‌ها را مسدود کند.
- **نمادهای نقره و مس تأیید نشده‌اند.** `silver_999` و واحد آن را روی صفحه‌ی TGJU چک کنید. تا وقتی نماد مس تنظیم نشده، مس در کانال منتشر نمی‌شود.
- **زمان‌بندی ۳۰ دقیقه‌ای** توسط GitHub Actions انجام می‌شود، چون Telegram Serverless تایمر ندارد. GitHub ممکن است چند دقیقه تأخیر داشته باشد و اگر ریپو ۶۰ روز بدون فعالیت بماند، زمان‌بندی‌ها غیرفعال می‌شوند.
- **کلید CMC داخل کد است.** فقط کدی که شما deploy می‌کنید در سرور تلگرام است، ولی اگر ریپو عمومی است، کلید را داخل `config.js` نگذارید.
